SQLite DB & Python Flask Integration Guide

1. Database Schema: Your SQLite file contains tables F1SIM_TELEMETRY, F1SIM_LAPTIME, and F1SIM_LAPDATA capturing Codemasters F1 22 UDP telemetry packets from mock-pi-01 on the Singapore track.

2. Flask Route Query: Connect via sqlite3.connect('f1_telemetry.db'), query lap times in milliseconds, and pass them into Jinja2 templates.

3. JSON Payload Injection: Inject query results directly into const RACE_DATA = {{ sqlite_data | tojson }}; to power live 60 FPS Canvas rendering and Plotly telemetry charts.
